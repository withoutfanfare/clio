## Assistant
To recap what we settled earlier in this session: the tracking poller runs on the default queue instead of `media`, because the poll is quick and light while `media` carries the heavy artwork jobs. It sends tracking numbers to Royal Mail in chunks of 30, since their API returns HTTP 400 for anything larger even though the documentation says 100. And when the API answers 429 it waits for the Retry-After period before trying again, because ignoring it gets the key suspended for an hour.
